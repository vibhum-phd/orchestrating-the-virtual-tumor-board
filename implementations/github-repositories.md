# GitHub Implementations

- **[microsoft/autogen](https://github.com/microsoft/autogen)** — Official AutoGen repository; actively maintained, extensively documented, and the underlying framework for the JCO-published virtual oncology tumor board system in this repo's reference list.
- **[gersteinlab/MedAgents](https://github.com/gersteinlab/MedAgents)** — Official code for the ACL 2024 MedAgents paper; well-documented multi-disciplinary LLM collaboration pipeline directly reproducible on the MedQA/PubMedQA/MMLU benchmarks it reports.
- **[mitmedialab/MDAgents](https://github.com/mitmedialab/MDAgents)** — Official code for the NeurIPS 2024 MDAgents paper; implements the complexity-adaptive solo/group collaboration structure and is actively referenced in follow-up medical multi-agent work.
- **[SamuelSchmidgall/AgentClinic](https://github.com/SamuelSchmidgall/AgentClinic)** — Official AgentClinic benchmark implementation; includes the multi-agent (doctor/patient/measurement/moderator) simulation harness and the MedQA/NEJM/MIMIC-IV case suites, with active release history through 2024.
- **[crewAIInc/crewAI](https://github.com/crewAIInc/crewAI)** — Actively maintained, well-documented role-based multi-agent framework with extensive examples; a practical starting point for prototyping a specialist-agent tumor board simulation.
